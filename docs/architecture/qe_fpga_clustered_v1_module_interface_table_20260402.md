# QE clustered v1 Module Interface Table (2026-04-02)

This table aligns each implementation-facing module with its cluster, ingress/egress contracts, local buffering, backpressure sources, KPIs, and workload knobs. The sources are the cluster-level specs and the implementation package annex.

| Module | Cluster | Role | Ingress | Egress | Local state / buffers | Backpressure source | Required KPIs | Workload-sensitive parameters |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Episode Controller | Episode Control Domain | Persistent scheduler that issues `panel_serial`, mediates cluster-start/stall, tracks fallback, and publishes `episode_continue_flag`. | Case descriptor (`case_id`, `npw`, `nkb`, `projector_mode`, `precision_mode`, `panel_serial`) + FIFO credit returns + `spill_report` + `P_next_commit` status. | Panel tokens, cluster gating signals, `cdiaghg_mode`, `episode_continue_flag`, `spill_markers`, resident-commit acknowledgements; optional host-export descriptors only on spill / episode-exit / debug. | `episode_status_register`, `resident_fit` counters, credit counters, fallback reason log. | Credit delays (`controller_sync_us`) and FIFO saturation reports across `fifo_ab`, `fifo_bc`, `fifo_cd`. | `service_time_per_episode_unit`, `stall_ratio`, credit-return latency, fallback frequency. | `controller_sync_us`, `onchip_resident_budget_kib`, `spill_penalty_us_per_kib`, supported workload bucket (small/medium/large). |
| Panel DMA / Memory Manager | Memory/DMA Domain | Streams Psi panels + projector/overlap data from off-chip, manages double buffers, aligns bursts for cluster A. | Host DMA commands, `psi_panel_kib` descriptors, `projector_state` updates. | `PsiPanelReceiver` ready signals, double-buffer pointers, backpressure tokens to host. | `Psi_panel_ping/pong`, `projector_bank`, `overlap_bank`, DMA queue depth, burst counters. | Off-chip bandwidth saturation, DMA queue limits, bank conflicts. | `Bytes_host_fpga`, load latency, buffer residency ratio. | `psi_panel_kib`, `projector_bank_kib`, `overlap_bank_kib`, burst size per workload. |
| PsiPanelReceiver | Cluster A | Ingests Psi tiles, tags panels with metadata, and keeps double-buffered staging aligned with panel order. | Panel tokens + descriptor (panel_id, row_block_id, `psi_panel` address). | `Psi_panel` tiles to `ProjectorOverlapBank`; readiness handshake to controller. | `psi_panel_ping/pong`, `panel_id` tags, `panel_prefetch_count`. | DMA stall due to `psi_panel` shortage or host throttle. | `T_A_load`, `occupancy`. | `panel_bands`, `row_block_size`, streaming lanes. |
| ProjectorOverlapBank | Cluster A | Maintains resident projector/overlap data keyed to basis metadata. | Controller updates of basis region + `projector_mode`. | Pointer to `FusedArrayEngine`, overlap ready flags. | `projector_state_bank`, `overlap_state`, metadata cache. | Misses forcing host fetch, leading to pipeline stall. | `resident_fit`, `projector_bank_hit_ratio`. | `projector_mode` (NC / USPP / PAW), `projector_bank_kib`. |
| FusedArrayEngine | Cluster A | Performs SIMD/systolic MAC array for `h_psi`/`s_psi` fused multiplies. | `Psi_panel`, projector/overlap tiles, `fft_mode` tokens. | Partial accumulation stream to `PartialReducer`. | Lane counters, `a_array_lanes`, `a_fft_lanes`. | Downstream FIFO fill (`partial_HS_fifo` above threshold). | `T_A_array`, `a_stream_lanes` utilization. | `row_block_size`, `panel_bands`, `psi_panel_kib`. |
| PartialReducer / Emitter | Cluster A | Converts lane outputs into `partial_HS_packets` and services FIFO. | Partial sums from array engine. | Packets to `A_to_B_partial_fifo`. | `partial_HS_fifo`, reduction tree state. | `fifo_ab` credit exhaustion or `b_accum_buffer` backpressure. | `T_A_emit`, `A_to_B_emit_utilization`, `stall_ratio_ab`. | `a_partial_fifo_kib`, `fifo_ab_kib`. |
| PartialAggregator | Cluster B | Gathers `partial_HS_packets`, performs accumulations for `H_sub/S_sub`. | `partial_HS_packet`, panel metadata. | Local accumulators (to `LocalReducer`). | `partial_HS_accum_buffer`, `b_accum_lanes`. | `partial_HS_fifo` emptiness forcing A stall. | `T_B_accum`, `Bytes_spill` (if buffer overrun). | `b_accum_lanes`, `b_accum_buffer_kib`. |
| LocalReducer | Cluster B | Collapses accumulated partials into reduced matrix tiles. | Accumulated partials, `row_block` metadata, controller tokens for emit readiness. | Reduced tiles to `MatrixStager`. | `H_sub_stage_buffer`, `S_sub_stage_buffer`, reduction work registers. | `B_to_C` FIFO blocks emission; stalled when `matrix_ready` queue exceeds `fifo_bc`. | `T_B_reduce`, `resident_fit`. | `row_block_size`, `b_reduced_stage_kib`. |
| DescriptorEmitter | Cluster B | Forms `reduced_matrices_descriptor` for Cluster C and applies resident hint + spill flag. | Reduced tile readiness + resident hint bits. | Descriptor to `B_to_C_reduced_fifo`, metadata to controller. | `reduced_descriptor_queue`, spill reporter. | `fifo_bc` credit shortage, controller-enforced barrier waiting for C. | `T_B_emit`, `reduced_matrices_ready_ratio`, `stall_ratio_bc`. | `b_reduced_emit_bw_kib_per_us`, `fifo_bc_kib`. |
| Diag Input Loader | Cluster C | Copies `H_sub/S_sub` into diag buffer, verifies `n_active`, triggers fallback if out of range. | `reduced_matrices_descriptor`, resident hints, `controller cdiaghg_mode`. | Ready work windows, fallback trigger. | `diag_input_buffer`, `c_input_buffer_kib`. | `c_input_buffer` overflow or `resident_fit` miss leading to fallback. | `T_C_input`, `resident_fit`, `cdiaghg_mode_selected`. | `c_reduced_dim_cap`, `c_input_buffer_kib`. |
| Factorization / Transform / Solver buckets | Cluster C | Execute Cholesky, transform, Hermitian solve, back-transform, output diag descriptor. | `H_sub/S_sub` windows, factorized headers, `c_solver_parallelism`. | `diag_solution_descriptor` to D + `crossover_margin`. | `eigvec_buffer`, `eigval_buffer`, `transform_workspace`, solver pipeline state. | `C_to_D_solution_fifo` saturation or buffer overflow. | `T_C_compute`, `T_C_emit`, `crossover_margin`, `T_C_factorize/transform/solver`. | `c_solver_parallelism`, `c_emit_bw_kib_per_us`, `c_eigvec_buffer_kib`. |
| Solution Distributor / Cluster D Refresh Engine | Cluster D | Consumes diag descriptor, computes residuals, updates `P_next`, sets continue flag. | `diag_solution_descriptor`, controller continuation token. | `P_next_resident_commit`, optional `P_next_spill_descriptor`, optional `P_next_host_export_descriptor`, `episode_continue_flag`, `residual_status` back to controller/A. | `refresh_scratch_buffer`, `residual_buffer`, `P_next_slots`, `episode_status_register`. | `C_to_D_solution_fifo` overload, `d_refresh_buffer_kib` excess. | `T_D_refresh`, `T_D_writeback`, `Bytes_spill`, `stall_ratio_cd`. | `d_refresh_lanes`, `d_writeback_bw_kib_per_us`, `d_pnext_slots_kib`. |
| Inter-cluster FIFOs | Inter-cluster streams | Carry packets between clusters (A→B partial, B→C reduced, C→D diagonal solution) and expose credits/backpressure. | Producer packets + headers. | Consumer-ready packets + credit acknowledgments. | FIFO depth registers, `credits_ab/bc/cd`, `spill_report` flags. | Downstream consumption stalls (saturated FIFO) or `resident_fit` spills on upstream cluster. | `fifo_*_peak_depth`, `stall_ratio_*`, `credits_*_inflight`. | `fifo_ab_kib`, `fifo_bc_kib`, `fifo_cd_kib`, `spill_penalty_us_per_kib`. |
