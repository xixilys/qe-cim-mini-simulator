# QE clustered v1 Buffer & Memory Budget Table (2026-04-02)

目的是把 `docs/architecture/qe_fpga_clustered_v1_*` 中的 resident、buffer、FIFO、spill 约定统一成一个面向实现的预算表，方便后续 FPGA 设计据此采集 KPI。表中每一行至少列出：对象 / 缓冲、预算参数、spill 优先级、带宽瓶颈、必须采集的最少指标，以及针对 five workloads（small-Si, Si8, graphene, Au slab, SiC32）的兼容能力提示。

## 1. On-chip resident objects
| Object | Cluster scope | Budget parameter(s) | Spill priority | Metrics to collect | Workload notes |
| --- | --- | --- | --- | --- | --- |
| `projector_state` | Cluster A / B | `projector_bank_kib` | 1 (resident must stay on-chip) | `resident_fit`, `projector_bank_util`, `Bytes_spill` | Small-Si: ample budget; Si8 & graphene: watch lookup latency; Au slab / SiC32: may force fallback if retrieval stalls. |
| `overlap_state` | Cluster A / B | `overlap_bank_kib` | 1 (shared across panels) | `resident_fit`, `overlap_bank_util`, `stall_ratio_ab` | Small-Si: low reuse; others rely on reuse -> misalignment inflates `Bytes_host_fpga`. |
| `partial_HS` | Cluster A → Cluster B handoff | `a_partial_fifo_kib` + `partial_HS_accum_buffer` | 2 (spills first when residence budget is tight) | `fifo_ab_peak_depth`, `stall_ratio_ab`, `Bytes_spill` | Graphene emits wide partials; Si8/Au slab pressure B-side barrier; SiC32 sees sustained emission and may need `flush` tokens. |
| `H_sub / S_sub` staging | Cluster B | `b_reduced_stage_kib` | 2 (eviction triggers `Bytes_spill`/penalty) | `resident_fit`, `reduced_matrices_ready_ratio`, `T_B_emit`, `Bytes_spill` | Au slab / SiC32: large matrices, stage buffer must grow; small-Si ok. |
| `diag_solution` window | Cluster C | `c_input_buffer_kib` + `c_eigvec_buffer_kib` + `c_eigval_buffer_kib` | 3 (last to spill, triggers fallback) | `resident_fit`, `cdiaghg_mode_selected`, `crossover_margin`, `Bytes_spill` | SiC32 tightest; graphene may pre-empt if `c_reduced_dim_cap` exceeded; small-Si comfortable. |
| `P_next_slots` + loop state | Cluster D | `d_pnext_slots_kib` + `residual_buffer` + `episode_status_register` | 3 (spill forces extra host writes) | `T_D_writeback`, `resident_fit`, `episode_continue_flag`, `Bytes_spill` | Au slab/SiC32 need larger `P_next` double buffer; small-Si uses minimal slots. |

## 3. Workload compatibility summary
- `small-Si`: narrowest `psi_panel` and `n_active` fit comfortably within all budgets; FIFO and resident metrics should show low `stall_ratio` and `Bytes_spill`.
- `Si8`: moderate `panel_bands` and `n_active` require tuned `b_reduced_stage_kib` and `c_input_buffer_kib`; watch `fifo_bc` depth and `cdiaghg_mode_selected`.
- `graphene`: high degeneracy makes partial emission & reduced bandwidth critical; prefer larger `a_partial_fifo_kib`, `b_reduced_stage_kib`, and proactive fallback when `c_reduced_dim_cap` crossed.
- `Au slab`: largest subspace size; stage buffers and `d_pnext_slots` must scale, and `spill_penalty_us_per_kib` should be monitored when `resident_fit` fails.
- `SiC32`: densest load to maintain; constant monitoring of `fifo_cd` stall ratio, `T_D_writeback`, and repeated `crossover_margin` evaluations avoid runaway host fallbacks.
